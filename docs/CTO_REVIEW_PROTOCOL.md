# Independent review protocol

Submit task ID, gate ID, exact remote SHA, branch, source paths, acceptance checklist, test commands/results and environment, CI links, known findings, evidence references and missing approvals. Reviewer must be independent of implementation for the gate, inspect the exact SHA and verify relevant tests or report NOT_RUN. Record REVIEW_READY, CHANGES_REQUESTED, REMEDIATING, RETEST_READY, APPROVED or BLOCKED; APPROVED requires an attributable external review record bound to the SHA. Planner reference presence is not authentication. New material changes invalidate affected approval and require retest. No self-approval, assumed approval or silent promotion. CORE-001 scoped engineering verification is not CTO Gate 01 approval. Gate 01 requires reproducible native/backend foundation, DB/auth tests and CI in addition to governance.
