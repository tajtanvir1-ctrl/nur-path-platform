# Test strategy

TDD for bounded behavior changes; retain red/green evidence where feasible. Unit tests, actual ASGI contract tests, real disposable PostgreSQL migration and ownership tests, Flutter unit/widget/native device tests, API/client integration, offline crash/retry/replay, localization/RTL/accessibility, AI locked holdouts, sandbox billing and restore tests. Use synthetic data and isolated test environments. Report command, exact source hash, environment, exit status, counts and limitations. No skipped test treated as pass. Coverage target 80% or higher for applicable new domain code, measured by module; coverage alone is insufficient. Independent security and scholar review are mandatory applicable release gates. Current health and governance tests are scoped only; see evidence-index.json.
