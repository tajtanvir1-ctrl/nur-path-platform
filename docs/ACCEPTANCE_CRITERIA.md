# Feature release criteria — draft V0.1

Every criterion below requires executable evidence where applicable, source/license review, negative cases, mobile accessibility, BN/EN/AR/UR, real API integration and scoped external approval; not a test result.

| ID | Minimum feature-specific acceptance |
|---|---|
| NP-F01 | Verified scholar assignment, access isolation, text/voice, payment idempotency, 18h escalation/24h reassignment or refund. |
| NP-F02 | Consented private audio; validated passage alignment; calibrated rule-specific feedback; abstain on unsupported rules; deletion and retries; independent speaker-disjoint holdout. |
| NP-F03 | Evidence labels distinguish certified, self-declared and unverified; expiration/report workflow; no investment guarantee. |
| NP-F04 | Only approved referenced bundles; opt-in/pause/delete; no private topic leakage, safe crisis referral. |
| NP-F05 | All 114 Surahs and edition verse manifest validated; immutable Arabic, attributed translations; offline search/bookmarks/resume. |
| NP-F06 | Rights-verified audio; playback interruption/resume and checksum-verified downloads; entitlement enforcement. |
| NP-F07 | Golden city/date cases, Hanafi/Shafi Asr, timezone/reboot and permission tests, offline Qibla fallback. |
| NP-F08 | Reviewed source/grading and rights for every published entry; persistent offline counters; no invented reward. |
| NP-F09 | Source integrity, citation validation, calibrated abstention, human escalation, multilingual held-out benchmarks; no critical error observed. |
| NP-F10 | Private default; offline progress, idempotent merge, no religious merit ranking. |
| NP-F11 | Verified daily content; real Android/iOS widget tests; timezone/reminder and sharing checks. |
| NP-F12 | Reviewed references, licensed audio, report/takedown; accessible playback. |
| NP-F13 | RBAC, reporting/blocking, moderation/appeal, minor protections, private data isolation. |
| NP-F14 | Transactional local packs, checksums, durable outbox, retry/replay/conflict and restart tests. |
| NP-F15 | Complete four-language UI; runtime switching, Arabic/Urdu RTL, reviewed religious translations. |
| NP-F16 | Sandbox purchase/restore, receipt verification, idempotent webhooks, quota and entitlement enforcement, cancellation/refund. |
| NP-F17–24 | Later-phase detailed acceptance and independent review required before implementation. |

Proposed religious AI targets: 5,000 multilingual evaluation cases, 100% reference integrity, >=98% scholar correctness, >=99% claim grounding, zero observed critical errors. Tajweed target 10,000 clips/500 speakers, precision >=95%, recall >=80%, rule-specific F1 targets and subgroup checks. Journey 2,000 cases, >=95% relevance, 100% source integrity. All targets unmeasured. No self-approved release.
