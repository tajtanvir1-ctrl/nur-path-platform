# Data governance — proposed baseline

Classify canonical religious text and licensed translations as controlled publication data; keep edition, source, rights and review metadata and immutable manifests. Identity, location, consultation, voice and reflection are private; minimize collection and require purpose-specific consent. No real private data in development fixtures, public repository or unapproved AI. Use tenant/user ownership, least privilege and audited access. Public community content remains subject to moderation and deletion. Financial events are exact integer ledger entries with immutable reconciliation. Define lawful retention and deletion schedules with jurisdiction review before release; do not invent statutory periods. User export/deletion, backup expiry, guardian consent and vendor processing controls require integration tests and release review.
